ماہنامہ نظامِ رنگ — آن لائن لائبریری
=====================================

کھولنے کا طریقہ
---------------
فولڈر unzip کریں اور index.html پر ڈبل کلک کریں۔ انٹرنیٹ پر شائع کرنے کے لیے پورا فولڈر
(GitHub Pages / Netlify / اپنی ہوسٹنگ) پر اپ لوڈ کر دیں۔

فولڈر کی ساخت
--------------
index.html                  لائبریری (افتتاحی اسکرین + تمام اشاعتیں)
links.html                  ہر اشاعت اور ہر صفحے کے لنک (کاپی بٹن کے ساتھ)
issues/<slug>/index.html    اشاعت کا ویور (ایک/دو صفحات، زوم)
issues/<slug>/page-01.html  اس اشاعت کا پہلا صفحہ — ہر صفحے کا الگ HTML
issues/<slug>/images/       صفحات کی تصاویر
data/issues.js              اشاعتوں کی فہرست (عنوان، مدت، ترتیب)
assets/                     ڈیزائن، کوڈ اور فونٹس
tools/add_issue.py          نئی اشاعت شامل کرنے کا اسکرپٹ

اگر صفحہ سفید / خالی نظر آئے
---------------------------
اس کا مطلب ہے کہ تصویر اپنی جگہ پر نہیں۔ ویور اب "تصویر نہیں ملی" کے ساتھ مطلوبہ فائل کا راستہ دکھاتا ہے۔
یقینی بنائیں کہ پورا فولڈر (issues/<slug>/images/ سمیت) ایک ہی جگہ ہے اور فائلیں الگ فولڈروں میں
بکھری ہوئی نہیں۔

لنکس کی مثالیں
---------------
لائبریری:            index.html
پوری اشاعت:          issues/2024-04/index.html
دو صفحات کھول کر:    issues/2024-04/index.html#6&v=2
کسی ایک صفحے کا لنک:  issues/2024-04/page-06.html

نئی اشاعت شامل کرنے کا طریقہ (مستقبل کے لیے)
-------------------------------------------
ضرورت: Python 3 اور poppler (PDF سے تصویر بنانے کے لیے)
  Windows: poppler for Windows ڈاؤن لوڈ کر کے اس کا bin فولڈر PATH میں شامل کریں
  Mac:     brew install poppler
  Linux:   sudo apt install poppler-utils

1) فولڈر میں ٹرمینل / کمانڈ پرامپٹ کھولیں اور یہ چلائیں:

   python3 tools/add_issue.py "feb2025.pdf" --slug 2025-02 --title "فروری ایڈیشن" --period "فروری 2025"

   (Windows پر python3 کی جگہ python لکھیں)

   --slug    لنک کا نام: صرف چھوٹے انگریزی حروف، اعداد اور ڈیش (مثلاً 2025-02)
   --title   لائبریری میں نظر آنے والا عنوان
   --period  مدت (اختیاری)
   --cover   کس صفحے کو سرورق بنانا ہے (ڈیفالٹ: 1)
   --width   تصویر کی چوڑائی پکسل میں (ڈیفالٹ 1300؛ زیادہ = صاف مگر بھاری، مثلاً 1600)
   --format  webp یا jpg (Pillow انسٹال ہو تو webp ڈیفالٹ ہے جو آدھی جگہ لیتا ہے)
   --quality معیار 1 سے 100 (ڈیفالٹ: webp 70، jpg 78)

   نوٹ: موجودہ سات اشاعتیں 1100 پکسل / webp میں ہیں۔ زیادہ صاف تصویر چاہیے ہو تو اصل PDF سے
   وہی slug اور --replace --width 1600 کے ساتھ دوبارہ بنا لیں۔

2) اسکرپٹ خود بخود یہ سب بنا دیتی ہے: صفحات کی تصاویر، ہر صفحے کا HTML، لائبریری میں
   نیا کارڈ اور links.html میں نئے لنکس۔

3) پورا فولڈر دوبارہ اپ لوڈ کر دیں (یا صرف نیا issues/<slug> فولڈر، اور data/issues.js اور links.html)۔

دیگر کمانڈز
-----------
اگر PDF کی بجائے تصاویر کا فولڈر ہو:
   python3 tools/add_issue.py --images "تصاویر_کا_فولڈر" --slug 2025-02 --title "..."
موجودہ اشاعت بدلنا (وہی slug + --replace):
   python3 tools/add_issue.py "new.pdf" --slug 2025-02 --title "..." --replace
اشاعت ہٹانا:
   python3 tools/add_issue.py --remove 2025-02
ترتیب بدلنا یا عنوان درست کرنا:
   data/issues.js کھول کر ترمیم کریں، پھر چلائیں:  python3 tools/add_issue.py --rebuild

Bombay Black Unicode فونٹ
-------------------------
فونٹ فائل کو assets/fonts/ میں BombayBlackUnicode.ttf کے نام سے رکھ دیں؛ عنوانات میں خود لگ جائے گا۔
(فائل نہ ہو تو متبادل نستعلیق فونٹ استعمال ہوتا ہے۔)
